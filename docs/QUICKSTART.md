# ⚡ Quickstart

## 1. Clone

```bash
git clone https://github.com/Priyanshu710-ui/youtube-ai-summarizer.git
cd youtube-ai-summarizer
```

## 2. Install

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate
pip install -r requirements.txt
```

## 3. Add your Groq key

Create your local environment configuration from the example file and add your API key. Never commit the real key.

## 4. Run

```bash
streamlit run app.py
```

## 5. Try it

Paste a YouTube URL, choose a summary style, and generate the result.
