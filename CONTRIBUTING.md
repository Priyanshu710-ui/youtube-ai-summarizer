# Contributing

Thanks for your interest in improving YouTube AI Summarizer.

## Quick start

1. Fork the repository.
2. Create a feature branch.
3. Create a virtual environment.
4. Install `requirements.txt`.
5. Run `streamlit run app.py`.
6. Test the change with videos that have available captions.
7. Open a pull request with a concise description of the change.

## Good first contributions

- Improve timestamp handling.
- Add multilingual transcript support.
- Improve summary formatting.
- Add transcript caching.
- Improve accessibility and responsive UI.
